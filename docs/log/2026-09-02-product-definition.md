# 2026-09-02 제품 정의 초기화

Goal 25와 파일을 나누지 않고, 사람용 정의만 적었다가, 이어서 **요한 OS ≠ 관제탑**을 정정했다.

질문을 다시 맞췄다.

1. 원래는 벡터·검수 **대시보드**로 시작했고, 달력·할 일 **앱**은 8월에 붙었다.
2. 앞문/뒷문이 아니라 **앱**과 **대시보드** 두 가지다. 설치는 관제탑 하나.
3. 앞 초안은 요한 OS를 brain(서랍)과 같은 말로 적었다. 오너 정정: OS는 지식 웹앱, 관제탑은 별도. 로컬에서 겹쳐 보이는 것은 이관 잔재 + 헤더가 "Yohan OS"였기 때문이다.
4. 저장소 리네임·지식 탭 분리·새 할 일 앱은 하지 않는다. 창 이름만 관제탑으로 둔다.
