## 집이 왜 더러운가

요한 OS(brain)는 **기억과 규칙의 서랍**이다. 관제탑은 원래 **그 서랍을 보는 탑**이었다. 노션은 **집 밖 AI가 서랍을 보게 하던 다리**였다. 스튜디오 OS는 복잡해져서 버렸다.

그다음 탑 안에 달력·할 일·인박스·지식 검토·`지금` 화면이 쌓였다. 이름도 직업도 섞였다. 시안 탭 이름과 실제 탭 이름이 다르다. Goal 25 번호가 PR #39와 겹친다. VISION은 빈 칸이었다.

치우는 방법은 레포를 지금 나누는 게 아니다. **무엇이 어느 집 물건인지**만 다시 붙이면 된다.

| 집 | 하는 일 | 안 하는 일 |
| --- | --- | --- |
| **brain (요한 OS 서랍)** | 문서 정본, 미션, 규칙 | 예쁜 달력 화면 |
| **관제탑 (화면 하나)** | 앱 + 대시보드. 달력 파일은 여기 옆 폴더 | 노션을 다시 본사로 |
| **노션** | 아직 집 밖 AI·폰 다리 | 할 일·일정의 본사 |
| **각 레포 Goal** | 개발 큰 목표와 쪼갠 할 일 | 치과·클라이밍 같은 삶 |

## 큰 그림 (두 가지)

한 설치, 포트 3001.

1. **앱** — 요한이 스스로를 관리한다. 달력, 일상 할 일, 개발 할 일, 문서, 던지기. 클라이밍·피아노·치과·이용권·연주회가 여기 산다. Cursor 같은 집 에이전트는 **달력 파일**을 읽는다.
2. **대시보드** — 한눈에 본다. 프로젝트, 에이전트, 스킬, MCP, 훅, 로그, 문서 라이브러리, 디자인 인텔리전스.

앞문 뒷문이 아니다. 직업이 둘이다. 탭 다섯 개를 같은 크기로 두면 노션이 다시 된다.

노션을 없앤 척하지 않는다. ChatGPT는 이 PC 폴더를 못 연다. MCP가 열리기 전엔 다리가 노션이다. 본사만 파일로 옮긴다.

이름은 탑에서 와서 하루용으로 딱딱하다. 저장소는 지금 안 바꾼다.

## 어떻게 쪼개서 만드나

한 번에 한 조각. 디자인과 개발을 같은 조각 안에서만 한다.

1. **달력이 쓰인다** — 시안 껍질, 선택 날, 빠른 추가, 동그라미 완료. Goal 25가 하는 중. 카테고리 점·이용권 UI 없음.
2. **집 에이전트가 헤매지 않는다** — 달력 폴더·필드 한 장. 새 화면 없음.
3. **링크** — 연주회 = 달력 사건 + 프로젝트. MOVA = 사람 말 큰 목표 + 쪼갠 할 일. 체크는 따로.
4. **이용권** — 기간·남은 횟수. 일정이 아님.
5. **대시보드 한눈** — 스킬·로그·디자인 인텔리전스는 앱이 열린 뒤.
6. **집 밖 다리** — 관제탑 MCP. 그때 “노션 대체”를 말한다.

치우기는 코드 대청소가 아니다. 새 조각에 **가짜를 안 넣는 것**이 치우기다. 낡은 Draft PR·Goal 번호 겹침은 달력 다음에 한 번에.
