## 집이 왜 더러운가

실패해서가 아니다. **집이 여럿인데 물건이 한 방에 쌓여서**다.

앞 초안은 요한 OS를 brain(서랍)과 같은 말로 적었다. 그건 틀렸다.

- **brain** — 기억·규칙 서랍. 파일이다. 화면이 아니다. env 이름 `YOHAN_OS_ROOT`는 이 경로의 옛 별명일 뿐, OS 웹앱이 아니다.
- **요한 OS** — 지식 웹앱. 문서, 벡터, 지식 검토. 관제탑과 **별도**다.
- **요한 관제탑** — 이 레포, 포트 3001. 달력·할 일·프로젝트 한눈. OS가 아니다.
- **노션** — 집 밖 AI·폰이 같은 메모를 보게 하던 다리. 본사가 되면 또 무거워진다.

스튜디오 OS는 이미 복잡해서 버렸다. 2026-07에 brain 대시보드(지식 화면)를 이 레포로 옮기면서 **한 localhost에 두 앱이 앉았다.** 헤더·탭 제목이 "Yohan OS"라 관제탑을 열면 OS와 겹쳐 보였다. 창 이름은 관제탑으로 맞춰 두었다. 지식 탭을 지금 뜯지는 않는다.

지금 할 일은 OS를 관제탑에 한 번 더 그리는 게 아니다. **물건만 제자리에 두는 것**이다. 저장소를 지금 나누지 않는다. 다만 이 창의 이름은 관제탑이다.

| 집 | 하는 일 | 안 하는 일 |
| --- | --- | --- |
| **brain (서랍)** | 문서 정본, 미션, 규칙 | 브라우저 앱 |
| **요한 OS (지식 웹앱)** | 문서·벡터·지식 검토 | 달력·할 일·이용권 |
| **관제탑 (이 레포)** | 앱(달력·할 일) + 대시보드(한눈) | 지식 OS를 다시 그리기, 노션을 본사로 |
| **노션** | 아직 집 밖 AI·폰 다리 | 할 일·일정의 본사 |
| **각 레포 Goal** | 개발 큰 목표와 쪼갠 할 일 | 치과·클라이밍 같은 삶 |

## 큰 그림 (관제탑 안의 두 가지)

한 설치, 포트 3001. **요한 OS와 같은 앱이 아니다.**

1. **앱** — 요한이 스스로를 관리한다. 달력, 일상 할 일, 클라이밍·피아노·치과·연주회, 나중에 이용권. Cursor 같은 집 에이전트는 **달력 파일**을 읽는다.
2. **대시보드** — 한눈에 본다. 프로젝트, 에이전트, 스킬, 로그.

앞문 뒷문이 아니다. 직업이 둘이다. 탭 다섯 개를 같은 크기로 두면 노션이 다시 된다.

지식 탭(문서·벡터)이 지금 이 창에 있는 것은 이관 잔재다. 지금 뜯어 새 앱으로 빼지 않는다. 새 조각에 OS 가짜를 넣지 않고, 창 이름을 OS로 두지 않는 것이 치우기다.

노션을 없앤 척하지 않는다. ChatGPT는 이 PC 폴더를 못 연다. MCP가 열리기 전엔 다리가 노션이다. 본사만 파일로 옮긴다.

저장소 이름은 지금 안 바꾼다.

## 어떻게 쪼개서 만드나

한 번에 한 조각. 디자인과 개발을 같은 조각 안에서만 한다.

1. **달력이 쓰인다** — 시안 껍질, 선택 날, 빠른 추가, 동그라미 완료. Goal 25가 하는 중. 카테고리 점·이용권 UI 없음.
2. **집 에이전트가 헤매지 않는다** — 달력 폴더·필드 한 장. 새 화면 없음.
3. **링크** — 연주회 = 달력 사건 + 프로젝트. MOVA = 사람 말 큰 목표 + 쪼갠 할 일. 체크는 따로.
4. **이용권** — 기간·남은 횟수. 일정이 아님.
5. **대시보드 한눈** — 스킬·로그는 앱이 열린 뒤.
6. **집 밖 다리** — 관제탑 MCP. 그때 “노션 대체”를 말한다.

치우기는 코드 대청소가 아니다. 새 조각에 **가짜를 안 넣는 것**이 치우기다. 낡은 Draft PR·Goal 번호 겹침은 달력 다음에 한 번에.
