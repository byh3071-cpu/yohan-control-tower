## 별도인 것들

| | 무엇인가 |
| --- | --- |
| **brain** | 파일 서랍. 화면 아님. `YOHAN_OS_ROOT`는 이 경로의 옛 env 이름 |
| **요한 OS** | 지식 웹앱. 문서·벡터·지식 검토. 이 레포가 아니다 |
| **요한 관제탑** | 이 레포. 달력·할 일·프로젝트 한눈 |
| **노션** | 집 밖 다리. 달력 본사 아님 |

로컬에서 한 창으로 보이는 것은 2026-07 이관 잔재다. 지금 레포를 나누지 않는다. 창 이름만 관제탑으로 둔다.

---

## 원래 뭐였나

2026-06 벡터 감시 대시보드로 시작했다. 7월에 brain 대시보드(지식 화면, 당시 이름 Yohan OS)와 합쳤다. 8월에 개인 달력이 붙었다. **지식 OS + 탑 이름 + 하루 앱**이 한 코드에 산다.

---

## 관제탑 안의 두 가지

| **앱** | **대시보드** |
| --- | --- |
| 내가 스스로를 관리하며 매일 씀 | 한눈에 봄 |
| 달력, 일상 할 일 | 프로젝트 현황, 에이전트, 스킬, 로그 |

지식 문서·벡터는 요한 OS의 일이다. 지금 이 창에 탭으로 남아 있어도, 관제탑의 직업으로 더하지 않는다.

노션은 달력 본사가 아니다. 새 할 일 앱은 안 만든다. 저장소 이름은 나중에.

---

## 노션을 코파일럿 DB로 쓰던 이유

ChatGPT 같은 집 밖 AI는 이 PC 폴더를 못 연다. 생각을 노션 페이지에 두면 집·폰·다른 AI가 “그 DB 봐”로 읽었다. 전사·노트도 그쪽이었다.

관제탑이 그걸 **화면으로** 대체하는 것과 **다리로** 대체하는 것은 다르다.

- 집 에이전트(Cursor 등)는 달력 **파일**을 이미 읽을 수 있다.
- ChatGPT·클로드 앱·제미나이는 MCP/API가 열리기 전엔 노션 다리가 맞다.
- 그래서 노션을 지금 끄지 않는다. 다만 할 일·일정의 **본사**로 쓰지는 않는다.

상세 기준은 `life-calendar-criteria.md`.

## 이름

관제탑은 대시보드 일에서 온 이름이라 하루용으로 딱딱하다. 저장소는 지금 안 바꾼다.
화면이 OS로 보이면 두 앱이 다시 한 방으로 보인다. 그래서 크롬 이름은 관제탑으로 고정한다.
